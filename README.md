## Profile

Embedded Systems Engineer working in Research & Innovation on refrigeration electronics. I take products from schematic to production: multi-layer PCB design in Altium Designer, bare-metal firmware in Embedded C, hardware bring-up, validation, root cause analysis and production support.

My personal work focuses on BLDC motor control, reusable firmware architecture and power electronics. Part of my professional work is proprietary, so this page presents my personal and open projects.
