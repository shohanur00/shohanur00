## 👨‍💻 About me

I build embedded products from the first schematic to the production line. My day-to-day work in R&I covers:

- 🔌 **Hardware:** schematic and multi-layer PCB design in Altium Designer, power supply design, hardware bring-up and validation
- 🧠 **Firmware:** bare-metal Embedded C on STM32, PIC, AVR and ESP32
- ⚙️ **Motor control:** BLDC drives, PID control and sensorless FOC
- 🏭 **Production:** test protocols, root cause analysis, SOP and BOM preparation, SMT line support

Some of my professional work is proprietary, so this page focuses on my personal and open projects.

## 🚀 Featured projects

| Project | What it is | Status |
|---|---|---|
| [**TurboSpin V2.0**](https://github.com/shohanur00/TurboSpin_V2.0) | BLDC electronic speed controller for high-speed drone motors on an STM32G431 with a DRV8301 gate driver and 8S battery support. Careful PCB layout with split grounds and isolated sensitive current paths. | Hardware complete, firmware running, sensorless FOC in development |
| [**G4_Core_Lib**](https://github.com/shohanur00/G4_Core_Lib) | Reusable bare-metal firmware framework for the STM32G431CB with a layered Application, Services, Drivers, BSP and HAL architecture. GPIO, TimeCore and logger modules are done. | In development |
| [**stm32g030f6p6_bootloader**](https://github.com/shohanur00/stm32g030f6p6_bootloader) | Bootloader firmware for self-programming (firmware update) on the STM32G030F6P6. | In development |
| [**RF-Remote-Controller-Project-Software-V1.0**](https://github.com/shohanur00/RF-Remote-Controller-Project-Software-V1.0) | RF remote controller for RC cars and drones on an STM32F401RCT6 with an nRF24 radio, designed for a range of about 1 km. | In development |
| [**stepper_motor_drive_stm32g030f6p6**](https://github.com/shohanur00/stepper_motor_drive_stm32g030f6p6) | Stepper motor drive firmware for the STM32G030F6P6. | See repo |
